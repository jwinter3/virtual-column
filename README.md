# Virtual column in pandas DataFrame

## Task

The task was to implement the `add_virtual_column` function, which takes a pandas.DataFrame containing data and returns a new pandas.DataFrame containing the original data and one new column whose value is calculated based on specified operations.
### Function Signature
```py
def add_virtual_column(df: pandas.DataFrame, role: str, new_column: str) -> pandas.DataFrame:
```

### Validations
- Column labels must consist only of letters and underscores (_).
- The function must support basic operations: addition (+), subtraction (-), and multiplication (*).
- If the role or any column label is incorrect, the function should return an empty
DataFrame.

## Solution
To solve this task, I used the [antlr4](https://www.antlr.org/) tool. The tool and library are installed using the pip tool. The appropriate packages are added to the [requirements.txt](requirements.txt) file. The tool is used to generate parsers for a given grammar. The description of the grammar of a mathematical expression accepted by the `add_virtual_column` function is contained in the [math_expression/MathExpression.g4](math_expression/MathExpression.g4) file. The rest of the files in the [math_expression](math_expression) directory were generated by [antlr4](https://www.antlr.org/) based on this grammar using the command:
```sh
cd math_expression
antlr4 -Dlanguage=Python3 MathExpression.g4
```
The `add_virtual_column` function accepts expressions that:
- contain basic operations: addition (+), subtraction (-), and multiplication (*),
- may contain parenthetical expressions,
- contain operations on columns (one or more) and numbers (ints, floats, etc.),
- may contain whitespace characters, i.e. spaces, tabs, newlines,
- column labels must consist only of letters and underscores (_).
- If the role or any column label is incorrect, the function return an empty
DataFrame.

Function `add_virtual_column` is in file [solution.py](solution.py).

## Tests
The file [test_virtual_column.py](test_virtual_column.py) contains unit tests for this task. In addition to the tests included with the task, it contains additional tests that I have implemented. In my tests, I check:
- correct result for expressions containing operations on more than two columns (e.g. sum of values from three columns),
- correct result for expressions containing operations on one column (e.g. ‘column’ or ‘-column’),
- correct result for expressions containing constants - only constants and constants and column values (e.g. ‘1+2’ or ‘2*column’),
- correct result for expressions containing parenthetical operations,
- correct result for more complex mathematical expressions,
- correct result for expressions containing ‘problematic’ column names, e.g. Python keywords such as ‘break’, ‘not’, “or”, ‘and’,
- correct result for expressions containing whitespace characters, i.e. spaces, tabs, newlines,
- empty DataFrame if the name of the new column is incorrect,
- empty DataFrame if the name of any column in the DataFrame is incorrect,
- empty DataFrame if ‘role’ contains an unknown operation, e.g. division,
- empty DataFrame if ‘role’ is incorrect,
- empty DataFrame if the columns on which the operation is performed do not contain numerical values.

### How to run the tests?

    ```sh

    ```
